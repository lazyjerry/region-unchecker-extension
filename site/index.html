歐盟 27 國，
不用再一國一國取消

還沒申報歐盟《數位服務法》（DSA）交易者身分時，App 的上架地區要排除歐盟國家。這個 Chrome 擴充套件在發布後台的國家／地區清單上，一次幫你取消勾選。

安裝擴充套件 看怎麼用

為什麼需要它

Google Play Console 沒有「排除歐盟」的選項，國家可用性也沒有能寫入的 API。每次上架或調整地區，都得在清單裡搜尋一個國家、取消、再搜尋下一個，27 國加上法國海外省，點錯一個就可能讓 App 在不該上架的地區出現。

使用方式

  1. 打開國家／地區編輯畫面在 Google Play Console 或 App Store Connect 進入上架地區的編輯頁。
  2. 選擇要取消的國家按工具列的套件圖示，勾選「歐盟 27 國」等清單，或補上其他國家名稱。
  3. 先預覽，再取消預覽會用紅框標示將被取消的國家；確認後按「取消勾選」。
  4. 自己檢查並儲存套件不會替你按儲存，送出前可以再看一次。

功能

  • 內建三組國家清單歐盟 27 國、法國海外省（後台分開列出時）、中國大陸，可自由組合。
  • 補充其他名稱一行一個國家名稱，完全相同才算命中，不會誤點「挪威」或「全選歐洲」。
  • 預覽模式先標示、不點擊，看清楚再動手。
  • 自動用搜尋框找清單上看不到的國家，會逐一輸入搜尋框找出來再取消。
  • 結果一目瞭然列出已取消、原本就沒勾、找不到的國家，不會靜默略過。
  • 中英雙語介面國家名稱涵蓋台灣與香港譯名，以及英文名稱。

隱私

不連網、不收集任何資料。你的選擇只存在瀏覽器本機，套件只在你按下按鈕時對目前分頁執行。詳見隱私權政策。

安裝

從 Chrome 線上應用程式商店安裝

商店頁面審核中，通過後會放上連結。

手動安裝（開發人員模式）
  1. 下載擴充套件 zip 檔並解壓縮。
  2. Chrome 開啟 chrome://extensions，打開右上角「開發人員模式」。
  3. 按「載入未封裝項目」，選擇解壓縮後的資料夾。

常見問題

會替我按「儲存」嗎？

不會。套件只取消勾選，儲存或送出一律由你自己確認後操作。

結果顯示「找不到」怎麼辦？

多半是後台使用的譯名不同。把後台顯示的國家名稱貼到「其他名稱」欄，一行一個，再執行一次。

App Store Connect 也能用嗎？

可以。不過 App Store Connect 的上架地區另有 API 可設定，若你已有自動化腳本，用 API 會更穩定。

冰島、挪威、瑞士、英國會被取消嗎？

不會。它們不是歐盟會員國，預設清單不包含。比對採完全相同的名稱，也不會誤點相似名稱的國家。

要不要排除歐盟，是誰決定的？

由你決定。本套件只是操作工具，不提供法律意見；是否需要申報 DSA 交易者身分，請依你的情況判斷。
